## 1. Problem statement

## 2. Goals and non-goals
Goals:
- Primary measurable outcome for this release.
- Secondary reliability or usability target.

Non-goals:
- Explicitly list adjacent features deferred to later milestones.

## 3. User stories and acceptance criteria
1. As a [role], I want [action] so that [outcome].

## 4. Non-functional requirements
- Availability target (for example 99.9%)
- Latency target (for example p95 under 250ms)
- Security and privacy requirements

## 5. Release and rollback criteria
- Automated tests pass in staging.
- Monitoring alerts and rollback steps are documented.
