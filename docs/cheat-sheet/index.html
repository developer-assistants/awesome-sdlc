SDLC developer cheat sheet

Concise one-page reference of phases, models, testing layers, and deployment strategies. Press Ctrl+P or Cmd+P to print cleanly.

7 phases at a glance

  1. Planning: scope, budget, timeline, risks.
  2. Requirements: PRD, SRS, acceptance criteria.
  3. Design: architecture, schema, API contracts.
  4. Implementation: code, PR reviews, CI checks.
  5. Testing: unit, integration, E2E, security, load.
  6. Deployment: canary, blue-green, migrations.
  7. Maintenance: monitoring, patches, post-mortems.

Model selection shortcuts

  • Requirements change weekly: Agile (Scrum / Kanban).
  • Fixed scope and contract: Waterfall.
  • Safety-critical or audited: V-Model.
  • High technical R&D risk: Spiral.
  • Clear core, phased features: Iterative.

Testing pyramid

  • Unit tests: fast, isolated functions (largest share).
  • Integration tests: DB queries, queues, API contracts.
  • End-to-end tests: critical browser or mobile journeys.
  • Non-functional: load, chaos, accessibility, SAST/DAST.

Deployment strategies

  • Rolling: replace instances in batches; low infra cost.
  • Blue-green: run two environments; instant traffic switch.
  • Canary: send 5% to 10% traffic to new version first.
  • Feature flags: decouple code deploy from user launch.
